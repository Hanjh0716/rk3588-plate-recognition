### Day 10 — OpenCV 读图、显示、保存

**学**：`cv2.imread` / `imshow` / `imwrite` / `resize` / `cvtColor`

**准备**：随便找几张图片放到 `~/datasets/images/`

**写**：`day10.py`
```python
import cv2
img = cv2.imread("路径/图.jpg")
print("形状:", img.shape)      # 注意是 (高, 宽, 通道)
print("尺寸: {} x {}".format(img.shape[1], img.shape[0]))
cv2.imwrite("output.jpg", img)
```

**要点**：
- **OpenCV 读进来是 BGR 顺序，不是 RGB**（以后接 matplotlib 显示会发现颜色不对，就是这个原因）
- `shape` 是 `(高, 宽, 3)` —— **先高后宽，别搞反**

- [ ] 完成
