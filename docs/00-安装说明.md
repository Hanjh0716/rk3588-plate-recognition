# 安装说明（照着做，约 30 分钟）

> 目标：把 Windows 电脑变成一台能做 AI 开发的 Linux 工作机。
> 全程免费，不需要买任何东西，不影响你现有的 Windows 和文件。

---

## 你需要做的事，一共 3 步

| 步骤 | 谁来做 | 耗时 |
|---|---|---|
| 1. 装 WSL2 + Ubuntu | 点脚本 → 点"是" → 重启 → 输用户名密码 | 10–20 分钟 |
| 2. 配 Python 环境 | 点脚本 → 输一次密码 | 5–10 分钟 |
| 3. 验证 | 点脚本 | 1 分钟 |

**你自己要动手的地方只有：点 3 次脚本、点 1 次 UAC "是"、重启 1 次、设置 1 个用户名和密码。**

---

## 第 1 步：安装 WSL2 和 Ubuntu

### 操作

1. 打开文件夹 `setup\`
2. **双击 `1-安装WSL.bat`**
3. 会出现 UAC 弹窗（"你要允许此应用对你的设备进行更改吗？"）→ **点"是"**
4. 黑窗口会跑起来，**按任意键开始**，然后等 5–15 分钟
5. 看到"安装命令已执行完毕"后，**按任意键关闭**

### ⚠️ 然后必须重启电脑

重启是强制的，不重启 WSL 用不了。

### 重启后设置 Ubuntu

重启后，Windows 通常会自动弹出一个 Ubuntu 终端窗口。如果没弹，从开始菜单搜 `Ubuntu` 打开。

第一次打开会让你设置：

```
Enter new UNIX username:        ← 输入英文小写用户名，例如: yun
New password:                   ← 输入密码（屏幕不显示字符，正常！盲打）
Retype new password:            ← 再输一遍
```

> **密码输入时看不见任何字符**——这是 Linux 的正常行为，不是你键盘坏了。输完直接回车。

设置完成后你会看到类似这样的提示符：

```
yun@DESKTOP-XXXX:~$
```

**看到这个，第 1 步就成功了。**

## 第 2 步：配置 Python 环境

1. 回到 `setup\` 文件夹
2. **双击 `2-配置Python环境.bat`**
3. 按提示回车，脚本会自动完成这些事：

| 自动安装 | 说明 |
|---|---|
| python3 / pip / venv | Python 本体和包管理 |
| git / curl / wget | 版本控制和下载工具 |
| build-essential | C 编译器，以后编译 OpenCV 之类的需要 |
| 清华 PyPI 镜像 | 让 `pip install` 从国内下载，快 10 倍 |
| `~/projects` 目录 | 以后代码放这里 |
| 虚拟环境 `.venv` | 隔离环境，避免"环境地狱" |
| numpy / opencv / matplotlib | 第一批要用的库 |

**过程中会要你输一次 Ubuntu 密码**（就是第 1 步设置的那个），同样不显示字符。

**最后看到"环境就绪！"就成功了。**

## 以后每天的工作流程

### 打开工作环境

从开始菜单打开 `Ubuntu` 终端，然后：

```bash
cd ~/projects/py-basics
source .venv/bin/activate
code .
```

- `cd ~/projects/py-basics` —— 进入项目目录
- `source .venv/bin/activate` —— 激活虚拟环境（看到命令行前面出现 `(.venv)` 就是成功了）
- `code .` —— 用 VS Code 打开当前目录

> **`source .venv/bin/activate` 这一步不能忘。** 忘了它，你 `pip install` 的东西会装到系统 Python 里，以后会出现"明明装了却 import 不到"的诡异问题。

### 在 VS Code 里

VS Code 会自动识别 `.venv`。如果右下角让你选解释器，选带 `.venv` 的那个。

然后就可以新建 `.py` 文件开始写代码，在 VS Code 的终端里（快捷键 `` Ctrl+` ``）运行：

```bash
python3 你的文件名.py
```

## 重要规则

### ✅ 代码放哪里

```
~/projects/           ← 代码放这里（WSL 内部，速度快）
/mnt/d/...            ← Windows 的 D 盘，从这里读写很慢，只用来放图片和数据集
~/datasets/           ← 数据集放这里
```

**不要把代码放在 `/mnt/d/` 下**。WSL 跨文件系统访问有严重性能损失，跑深度学习会慢到让你以为是代码问题。

### ✅ 每个新项目都要建虚拟环境

```bash
mkdir -p ~/projects/新项目名 && cd ~/projects/新项目名
python3 -m venv .venv
source .venv/bin/activate
pip install 你需要的库
```

### ✅ 遇到报错

复制报错内容 → 粘贴到 `docs\踩坑记录.md` → 搜一下或直接问我。

**报错时看最后一行**，那才是真正的错误原因。

## 常见问题

**Q: `wsl --install` 失败或卡住怎么办？**
可能是 Windows 版本太旧。打开 PowerShell 运行 `winver` 看版本，需要 **Windows 10 2004（内部版本 19041）以上**。把版本号告诉我。

**Q: 重启后 Ubuntu 窗口没出现？**
开始菜单搜 `Ubuntu` 手动打开。

**Q: 忘了 Ubuntu 密码？**
在 Ubuntu 里运行 `sudo passwd $USER` 可以重设（需要旧密码）。实在忘了告诉我，有命令行方式重置。

**Q: 脚本一运行就闪退？**
说明脚本本身报错了。右键脚本 → 以管理员身份运行，看具体报错，然后发给我。

**Q: 想彻底卸载重来？**
PowerShell 里运行 `wsl --unregister Ubuntu`，然后重新跑步骤 1。**数据会全部丢失**，所以先跑 `4-备份环境.bat`。

**Q: 占多少空间？**
Ubuntu + Python 环境约 3–5 GB，放在 C 盘。要搬家的话告诉我。
